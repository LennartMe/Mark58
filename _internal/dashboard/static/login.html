Voice commands aren't working

Browsers only allow microphone access on a secure origin, so a plain http:// address on your network gets blocked. Tell Chrome to trust this one:

  1. Open chrome://flags
  2. Search for Insecure origins treated as secure
  3. Add this page's address, then tap Relaunch
